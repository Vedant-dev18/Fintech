
# FinSight AI — AI-Powered Financial Analyst

FinSight AI is a Python-based financial analysis and
decision-support application that helps businesses
understand their financial performance.

## Features

- CSV financial data upload
- Revenue and expense analysis
- Interactive financial charts
- SQLite database storage
- AI-powered financial insights
- Business recommendations
- Conditional financial analysis using LangGraph
- Python-based financial calculation tools
- AI tool-calling prototype

## Technology Stack

Python, Streamlit, Pandas, Plotly, SQLite,
LangGraph, LangChain, Groq API and GPT-OSS 20B.

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Create a `.env` file containing:

   GROQ_API_KEY=your_own_groq_api_key

5. Run the application:

   streamlit run app.py

## Current Status

The core financial dashboard and conditional
LangGraph analysis are functional.

AI tool calling has been tested separately.
Dashboard integration and PDF report generation
are planned enhancements.
